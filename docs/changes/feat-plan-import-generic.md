# 計画の取り込み: ほかの形式の JSON (days と steps) も読む

## 不具合
- `generic_training_plan_v1` のように、日ごとに `steps` (type・distance_km・pace_min_per_km: "5:15-5:40"・interval の repeats) を持つ JSON を読み込むと「計画が見つかりません」になっていた
  (読めるのは STRIDE の形と COROS のプランを書き出した形だけだった)

## 変更
- `days: [{ date, name, steps }]` の形を読む
  - 種類: 休養 (sport: rest)・レース (type: race)・繰り返し (速ければインターバル、それ以外は LT走)・ロング (名前か 20km 以上)・巡航/ペース走 (steady 区間) → Mペース走・回復/調整 → Jog・それ以外 → Easy。流し付きのジョグは Easy
  - ステップ: アップ・ダウン・繰り返し (本数・1 本・レスト)・距離または時間・ペース範囲 ("4:35-4:40")。ペースが無い流しは COROS のゾーンの書きかたから
  - 計画のペース: ポイント練は速い区間 (繰り返しはその 1 本)、それ以外はいちばん長い区間
  - メモに名前・目的・シューズ・注意を入れる
  - 読めない日・ステップは除いて表示 (推測で埋めない)

## 変えていないもの
- COROS・Strava の連携、既存の取り込みの形
