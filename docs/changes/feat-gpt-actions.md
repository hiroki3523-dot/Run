# 拡張機能: ChatGPT 連携 (GPTs の Actions)

ChatGPT の有料プランを使う人だけが使う、オプションの機能。設定 › 拡張機能 で「使う」を押したときだけ動く (ふだんは止まっている)。

## できること
- ChatGPT (自分専用の GPT) が STRIDE を読む: 今日の状態 (体調・体重・次のレース・今日と明日の計画)・最近のラン・1 本の詳細 (1km ラップ・評価・ふりかえり)・計画・レース・シューズ
- ChatGPT が作った計画を STRIDE に登録する (画面の「貼り付け」と同じ取り込み)
  - 今日より前の日は入れない・置き換えでも走った記録と結びついた計画は残す
  - 種類・日付が不正な日は入れずに理由を返す
  - GPT への指示で「内容を見せて、登録してと言われたときだけ登録」を求める

## 安全のため
- 鍵は APP_TOKEN とは別の「ChatGPT 用の鍵」(kv の gpt_token)。設定で発行・作り直し・停止。バックアップには入れない
- この鍵で使えるのは /gpt/* の読み取りと計画の登録 (POST /gpt/plans) だけ。ランの記録・COROS・Strava・設定・バックアップには触れない
- 説明書 (OpenAPI) は /gpt/openapi.json (鍵なしで読める。中身は入口の説明だけ)

## 変えていないもの
- COROS・Strava の連携・同期、既存の API (/api/*) と APP_TOKEN

## テスト (ローカルで実行)
- gpt: 鍵の発行前・APP_TOKEN・作り直し前の鍵・停止後は 401／読み取り各種／計画の登録 (今日より前・不正な種類は理由付きで除外、走った日の計画は残す、ステップ)／ほかの書き込みは 405／鍵がバックアップに入らない
- e2e: 設定の拡張機能 (ふだんは止まっている → 使う → やめる)
- 全体: 182 件合格・1 件スキップ (known-issues、従来どおり)
