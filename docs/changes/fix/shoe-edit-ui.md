## 変更前と変更後の違い

| 画面 | 変更前 | 変更後 |
|---|---|---|
| シューズの編集 > どんな練習で使う？・状態 | 大きなボタン (「リカバリー・ジョグ」など長い文字) で画面を占める | 小さなボタンに、短い名前 (イージー・リカバリー・ロング・ペース走・スピード・レース)。選ぶと下に説明が出るのは今までどおり |
| シューズの編集 > 写真 | 写真の枠が大きく、写真の「削除」とシューズの「削除」が同じ名前 | 写真の枠を小さく、ボタンを「写真を外す」に |
| シューズの編集 > 使用感 | いちばん下で閉じていて気づきにくい | 用途のすぐ下に、紫の枠で「使用感 (走った感覚)・入力済みの数」。シューズの詳しく →「使用感」→「使用感を入力・編集」から開くと、最初から開いた状態 |

## 変更した理由

- ユーザーの指摘 (ボタンが大きすぎる・使用感の編集に気づかない)

## 既存機能への影響

- 見た目と並び順だけ。保存する値 (用途・状態・使用感) と保存のしかたは同じ

## 残っている問題

- なし
