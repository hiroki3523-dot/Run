## 変更前と変更後の違い

| 画面 | 変更前 | 変更後 |
|---|---|---|
| ホーム | 今日の予定・体調・レース・天気・目標・月間・週間グラフ・週間天気・ニュースが縦に並ぶ | ① 今日のトレーニング (枠で強調・ステップは 1 行ずつ・走った日は実績へのリンク) ② 今週の走行距離 / 計画 (計画画面へ) ③ 今朝の体調 ④ 次のレース (コンパクト・ペース表/持ち物へ) ⑤ 目標への現在地 ⑥ レース天気 ⑦ 月間目標 ⑧ 週間距離のグラフ (折りたたみ) ⑨ 週間天気 ⑩ ニュース (初めは 5 件・「もっと見る」) |
| レース詳細 | 大きなグラデーションの見出し | 見出しを小さく。目標・平均ペース・スタート時刻の 3 つの数字をタブの上に |
| シューズの詳しく | 大きな写真・相性は数字の表 | 写真は小さく横に。累計距離 (手入力の補正を含む)・目安 (設定値)・使用回数 / 相性: 「このシューズの傾向」を先に、種類ごとの本数と距離の棒、細かい数字は折りたたみ / 使用履歴: 月ごとの距離は直近 6 か月 (それより前は「さらに表示」)、「累計距離とは数え方が違う」と明記、ランは日付・種類 (計画が無いランは記録名)・距離・ペース・評価 / 使用感: 7 項目をバーで、入力済みの数、編集ボタン |
| 全画面 | 下のメニューに最後の行が隠れることがある | 下の余白を広げた (画面テストで確認) |

## 変更した理由

- ホーム・レース・シューズ画面 改善指示書 (UI/UX のみ)

## 既存機能への影響

- 表示だけの変更。評価・予測・距離・ペース・補給の計算は変えていない
- シューズの累計距離 (Nike Run Club に合わせた手入力の補正を含む) は変えていない。使用履歴の月ごとの距離とは別の数字として見出しを分けた
- ホームの週間距離のグラフは折りたたんだだけ (開けば今までどおり)。ニュースも残りは「もっと見る」で全部見られる
- 連携処理 (COROS・Strava) は変更なし

## 残っている問題

- 指示書の画像にある「相性スコア」「体調スコア 80」のような点数は、計算の根拠が無いので出していない (指示書の「計算式の変更は範囲外」に従った)
- レースの関門表・大会情報の並べ替え (当日よく見る項目を先に) は次回
- iPhone の Safari での見え方は画面テスト (Chromium・幅 390) でしか確かめていない

## ユーザーによる確認が必要な操作

1. ホーム: 今日のトレーニングが一番上にあり、文字が重なっていないか
2. シューズの詳しく: 累計距離が今までと同じ (NRC に合わせた値) か
3. 各画面のいちばん下が、下のメニューに隠れていないか
