## 変更前と変更後の違い

| 画面 | 変更前 | 変更後 |
|---|---|---|
| 実績 > 一覧 | ランを 1 本ずつ並べる | 日ごとにまとめる (同じ日のアップ・メイン・ダウンを 1 枚に、メインを強調)。直近 7 日の距離・本数・平均評価 (前の 7 日比)。種類で絞り込み (ポイント・ロング・Easy/Jog・レース)。30 日ずつ読み込む |
| 実績 > 日 | 等級とコメント | 日次評価・合計距離と計画比・本数・時間・負荷 / この日の練習 (アップ→メイン→ダウン) / **評価対象** (評価した区間の距離・記録全体・区間の平均ペース・目標・目標帯の割合・区間の根拠) / 主観とデータの照合 / まとめ (総合評価・最も重要な発見・次の一手・良かった点・課題) / 採点の根拠 (折りたたみ)。前日・翌日へ移動 |
| 実績 > 週 | 等級・丸い日ごとの表示 | 週間距離・計画比・前週比 / 曜日ごとの棒グラフ (実績・計画の枠・色は練習の種類) / 回数・走った日・ポイント・ロング / 週評価 (量・強度・質・回復) / 先週からの変化 (距離・平均ペース・平均心拍) / 疲労・睡眠・痛み (朝の体調) / 翌週への提案 |
| 実績 > 月 | 等級とコメント | 月間距離・目標・前月比 (月の途中は「暫定」) / 練習の内訳 / 練習カレンダー / 週ごとの距離 / 月間の成長分析 (同じペースにそろえた心拍の前月比・ロング走とポイント練) / 月の評価 (折りたたみ) |
| ランの詳細 > 良かった点・課題 | 「距離 (参考)」が課題に出ることがあった | 出さない (点数に入れていない参考値で、アップ・ダウンを別の記録にした日は計画の距離と比べられないため) |

## 変更した理由

- 指示書 v3.0 第3段階 (一覧・日) と第4段階 (週・月)。リデザイン案の画像を情報の優先順位の参考にした (画像の数値はダミー)

## 既存機能への影響

- API: `/review` に `prev_detail` (前の期間の平均)・`growth` (成長分析)・`days[].plan_km/main_type/score`・`breakdown`・`next_period` を**追加** (今のキーは変えていない)。`/activities` に `eff_type` を追加
- 日・週・月の評価の点数の計算は変えていない
- 下のメニュー・4 つのタブ・日付の移動・ランの詳細への移動はそのまま
- 連携処理 (COROS・Strava) は変更なし

## 残っている問題

- 1 記録の中のアップ・メイン・ダウンは、まだ計画のステップがあるときだけ区切れる (S-01・区間の調査中)。日の画面の「評価対象」に、区間の根拠 (計画のステップ / 推定・参考) を出している
- 月の成長分析は、計画の無いラン (フリー) を比べる対象に入れていない
- 一覧の小さなペースのグラフ (リデザイン案にあるもの) は入れていない

## ユーザーによる確認が必要な操作

1. 実績 > 一覧: 11/1 がアップ・メイン・ダウンの 1 枚になっているか
2. 実績 > 日: 11/1 の「評価対象」が メイン 12km になっているか。前日・翌日に移れるか
3. 実績 > 週・月: 数字が自分の記録と合っているか (10/26〜11/1、10 月)
