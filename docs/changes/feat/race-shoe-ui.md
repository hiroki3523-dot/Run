## 変更前と変更後の違い

| 画面 | 変更前 | 変更後 |
|---|---|---|
| 計画 > 週のカレンダー | アップ・メイン・ダウンのステップがある計画が、横に重なってぐちゃぐちゃに出る | 1 行ずつ縦に並ぶ (原因: ステップの一覧と −/＋ 入力の名前 `stp` が重なっていた) |
| 実績 (一覧・日) | ロング走の計画の M ペース区間が「ロング走」 | 「ロング走 (Mペース)」 |
| レース一覧 | 状態ごとのグループ | 次の出場予定の大会を大きく (状態・本命 (優先度 A のときだけ)・日付・残り日数・距離・目標タイムとペース。日付が暫定なら残り日数は出さない) / 今後の大会を日付順に (状態のバッジ・エントリー時期) / 過去の大会は折りたたみ。大会 0 件の案内 |
| レース詳細 | 縦に長い 1 枚 | 上に大会のまとめ。「概要・戦略・準備・実績」のタブ (押すとその場所へ・スクロールに合わせて切り替わる) / ペース表に「補給」の列 (補給計画の地点をその行に。登録が無ければ空欄) / 実績: 大会前は「目標への準備状況」(予測・出典・時点・目標との差・練習の目安。次の大会だけ)・大会後は結果 |
| シューズ一覧 | 使用中・予備/引退の一覧 | 用途で絞り込み (すべて・ジョグ・ポイント・ロング・レース) / 用途のタグ・目安に対する割合 (%)・最終使用日と回数 / 使用中・予備・引退 (折りたたみ) に分ける。タップで「詳しく」 |
| シューズの詳しく (新規 `#/shoes/:id`) | なし (タップで編集) | 写真・用途・状態・累計・目安・使った回数と期間 / 相性 (種類ごとの傾向・ほかのシューズとの差) / 履き分けの提案 (これから 7 日の計画) / 使用履歴 (月ごとの距離・レースでの使用・使ったラン) / 使用感 (7 項目・未入力は未入力)。「編集」から今までの編集画面 |

不具合の修正 (K-09・確認済み): レース詳細で決めた **補給計画・ペース表の型・区間の調整・スタートロス**が、保存しても残っていなかった (PR #110 から)。サーバー側で大会情報を整える処理がこれらの項目を落としていた。残るように直した。

## 変更した理由

- レース・シューズ画面 改善指示書 v1.0 (P1: レース一覧・詳細・シューズ一覧 / P2: シューズの詳しく)
- 計画のステップの表示はユーザーの指摘 (スクリーンショット)
- 「ロング走 (Mペース)」はユーザーの了承

## 既存機能への影響

- API (追加のみ): `/shoes` に `last_date`・`first_date`・`runs`、`/shoes/:id/history` (新規・読み取りのみ)、`/review` の各ランに `plan_type`
- K-09 の修正で、これから保存する補給・ペースの型などが残るようになる (以前に保存しようとした分は残っていないので、もう一度入れる必要がある)
- シューズ一覧のタップは「詳しく」へ (編集は詳しくの画面のボタンから)。スライドで予備・引退は今までどおり
- ペース表・通過時刻・関門・大会情報・持ち物・結果・天気・相性・おすすめは残している
- 連携処理 (COROS・Strava) は変更なし。評価・点数の計算も変更なし

## 残っている問題

- 「達成可能性 ○%」のような確率は出していない (算出の根拠が無いため)。予測は出典と時点つきで表示
- シューズの購入日は記録していないので出していない
- 準備状況は「次の大会」だけ (ホームの「目標への現在地」と同じ計算)

## ユーザーによる確認が必要な操作

1. 計画: アップ・メイン・ダウンの計画が 1 行ずつ並んでいるか (11/3 のインターバル)
2. レース詳細: 補給計画で地点を追加 → 画面を開き直しても残っているか・ペース表の「補給」の列に出るか
3. シューズ: 一覧のタップで「詳しく」が開き、使ったランが自分の記録と合っているか
