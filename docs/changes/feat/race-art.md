## 変更前と変更後の違い

| 画面 | 変更前 | 変更後 |
|---|---|---|
| レース詳細・レース一覧・ホームの次のレース | 紫のグラデーション、または自分で選んだ写真 | **自動で作る景色の画像** (アプリの中で描くオリジナルのイラスト。都市の夜景・海辺の都市・海と夕日・山並み + 走るコースの光の線)。大会名・会場から景色を選ぶ (例: 福岡 → 海辺の都市、東京 → 都市、湘南 → 海、富士山 → 山)。大会ごとにビルの並びや太陽の位置が少しずつ違う |
| 見出しの画像の選び方 | カメラのボタン → 写真を選ぶ | カメラのボタン → おすすめ (自動) / 都市 / 海辺の都市 / 海 / 山 / 自分の写真 / 写真を選ぶ / 画像なし / 写真を削除。小さな見本つき |
| シューズの編集 (PR #123 の内容を含む) | 大きなボタン・使用感が下で閉じている | 小さなボタン・使用感を用途のすぐ下に |

すでに写真を選んだ大会も、まずは自動の景色に戻る (写真は消していないので「自分の写真」で戻せる)。

## 変更した理由

- ユーザーの指摘 (大会の写真がダサい・スタイリッシュなイメージ画像を自動で作ってほしい・都市型や海などのイメージで他の大会も)
- 大会の公式写真などは著作権があるので使わず、アプリの中で描くオリジナルの絵にした

## 既存機能への影響

- 画像は保存せず、開くたびに描く (データは「どの景色にするか」だけを大会情報に保存)
- 計算・連携・ほかのデータは変更なし

## 残っている問題

- 景色の自動の選び方は大会名・会場の言葉から。合わないときは手で選ぶ

## ユーザーによる確認が必要な操作

1. 福岡マラソン2026 の詳細で、景色の画像が出るか (自分の写真のままなら、カメラのボタン →「おすすめ」)
2. 気に入らなければ、都市・海・山などを選び直す
