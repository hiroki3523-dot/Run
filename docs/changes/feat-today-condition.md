# 今日の体調に体重・体脂肪率をまとめる / ボタンの重なり・保存ボタン

## 変更
- ホームの「今朝の体調」と「からだ」を 1 枚の「今日の体調」にまとめた
  - 体重・体脂肪率を大きく表示 (ヘルスケアから届いた値には「ヘルスケア」の印)・4 週前との差
  - 適正体重: 体脂肪率 (7 日平均) から除脂肪体重を出し、体脂肪率 10〜12% のときの体重の幅。身長があれば BMI 18.5 を下回らない
  - 目標体重 (自分で決めた値。無ければ適正体重の上側) まで「あと何 kg」とバー
  - 目標まで落としたときのタイムの目安 (体重 1% ≈ タイム 1%)・最近 4 週の 1 週あたりの増減と、減るペースが速すぎるときの注意
  - 35 日の体重グラフ (目盛り・日付・適正体重の帯・目標の線)
  - 体調の入力画面で体重・体脂肪率も入れられる (＋−で 0.1 ずつ)。1 つの保存ボタンで両方を保存
  - 体重・体脂肪率を変えなかったときは、ヘルスケアから届いた値をそのまま残す。心拍・HRV・睡眠は消さない
- 目標体重・身長の入力 (PUT /body-profile は送った項目だけ変える)
- カードの見出しの右のボタンが、下の中身に重ならないように (全画面のカード共通)
- ダイアログの保存ボタンを、体調の保存と同じ大きく目立つ色に (全ダイアログ共通)

## 変えていないもの
- COROS・Strava の連携・同期・Webhook、POST /api/body (ショートカット) の受け取り方
- 既存の体調・体重のデータ (形式も同じ)
