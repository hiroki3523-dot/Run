# シューズを保存したあと画面が重く・表示されない / 相性の表で写真の位置がずれる (2026-11-05)

## 1. 保存後に重く・表示されない (iPhone)
ユーザー報告: シューズ名を変えて保存したあと、画面がやたら重くなって表示されない。アプリを再起動すると戻る。

- 再現: この環境 (Chromium) では再現しなかった (保存 → 再描画 5 秒以内・通信 6 回・エラーなし)。iPhone の Safari は試せない
- 推定の原因: 名前の入力中 (キーボードが出たまま) に保存すると、ダイアログが閉じてもフォーカスが残り、iPhone で画面の位置 (visualViewport) がずれたまま再描画される。以前の「一番下まで表示されない・スクロールできない」と同じ症状の可能性
- 変更 (public/app.js):
  - 保存・キャンセルを押した時点で入力欄のフォーカスを外す (キーボードを先に下げる)
  - ダイアログを閉じたら、キーボードが下がって画面の高さが戻るまで (最大 0.6 秒) 待ってから次の処理へ
  - 画面の描き直しが続けて呼ばれたときは、最後の 1 回だけを画面に出す (古い描画が後から上書きしない)

## 2. 相性の表で写真の位置がずれる
- 原因: 見出しを下ぞろえにしていたので、名前の行数 (1〜2 行) で写真の高さが変わった
- 変更: 上ぞろえにして、1 行目 = ブランド・色/呼び名 (小さく)、2 行目以降 = モデル名 (2 行まで・高さは常に 2 行分)。写真・本数の位置はそろう

## テスト
- e2e: 入力中に保存してもフォーカスが残らず画面が描き直される / 名前の長さが違っても写真と本数の位置がそろう (差 1px 以内)
