# シューズの相性のピッチ・ストライド / 引退・予備の扱い / 月の「前月」の距離 (2026-11-04)

ユーザー報告:
1. ピッチ・ストライドが正確でなさそう (Strava と STRIDE で靴の名前が違うから?)
2. 引退した靴を相性のランキングに入れたくない (記録は残す)
3. 予備の靴が引退と同じ扱いになっている
4. 11 月の画面の「前月 338.2km」と 10 月の画面の 353.5km が合わない

## 1. ピッチ・ストライド
- 名前は原因ではない: ランと靴は Strava の gear ID でつないでいる (名前ではない)。STRIDE で名前を変えても記録は同じ靴に付く
- 原因 (推定): 相性のピッチは、分析の要約 (`snap:`) があればそれを優先していた。K-01 (ピッチ 2 倍) を直す前に保存された要約は 2 倍の値 (約 356) のまま残る。アルファフライ 3 の 228.4 は、Strava の記録 (平均 88〜92 歩/分 × 2 = 176〜184) と合わず、7 本中 2 本が 2 倍なら説明できる
- 変更 (`/shoes/compare`): ピッチはランの記録の値 (avg_cadence_spm) を使い、無いときだけ要約。120 未満・230 超は平均に入れない。ストライドは「距離 ÷ 時間 ÷ ピッチ」で計算 (表のペース・ピッチと食い違わない。要約の無い靴にも出る)
- 保存済みの要約・記録は書き換えていない

## 2. 引退した靴
- 相性の表・おすすめ・緑の印から外す。「引退したシューズも表示」のチェックで右端に「引退」の印付きで出せる (おすすめには入れない)
- 記録・シューズ自体は消さない

## 3. 予備の靴
- 一覧で予備を引退と同じように薄く表示していたのをやめた (薄いのは引退だけ)
- 相性の比較には入れる (引退とは違う)
- 今日のシューズのおすすめ (画面・朝の通知): 使用中に合う靴が無いときは予備から選ぶ (前は予備を一切選ばなかった)。引退は選ばない

## 4. 月の「前月」
- 原因: 前の期間を「同じ日数だけ前」で作っていた。11 月 (30 日) の前月が 10/2〜10/31 になり 10/1 の分が抜けた。10 月 (31 日) の前月比は 8/31〜9/30 と比べていた
- 変更: 月は前の月の 1 日〜末日と比べる。週・日はそのまま
