# 計画の画面をすぐ開く

## 原因 (コードから)
- 計画の画面は、週間天気 (外の天気サービスへ 2 回、待ち時間の上限なし) が届くまで画面を出していなかった
- アプリを開いて最初に計画を開くときは、そのあとさらにシューズの相性 (1 年分のランと分析) の計算を待っていた

## 変更
- 計画・実績・設定・シューズだけ待って、すぐ画面を出す。天気とおすすめシューズ (相性込み) は、届いたらその欄だけ埋める
- 天気サービスへの問い合わせに上限時間 (5 秒・補正用は 4 秒)。届かなければ天気なしで表示 (補正は従来どおり既定のモデル)

## 変えていないもの
- COROS・Strava の連携・同期、計画やランのデータ、シューズの相性の計算方法

## テスト (ローカルで実行)
- e2e に「天気・相性の応答を止めた状態でも計画が 5 秒以内に出て、天気が届いたら埋まる」を追加
- 全体: 168 件合格・1 件スキップ (known-issues、従来どおり)
