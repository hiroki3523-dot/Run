# COROS のラップをちょうど 1.00km で区切る

## 不具合
- 長いラン (フルマラソンなど) のラップの距離が 0.99km・1.01km になっていた
- 1 秒ごとの記録を 3600 点に間引いてから区切っていたため、1km の地点が最大 10m ほど前後にずれていた

## 変更
- 間引く前の 1 秒ごとの記録で、ちょうど 1km の地点の時間・標高を前後の記録から補って区切る (どのラップも 1.00km)
- 最後の端数のラップにも平均心拍を出す
- 一時停止の時間を除く計算 (#147) はそのまま

## 変えていないもの
- COROS の通信・認証・同期の流れ、合計の距離・時間 (利用者の了承済みの範囲: 受け取った記録を区切る計算だけ)
- これから入るランから正しくなる (過去のランの取り直しはしない)

## テスト (ローカルで実行)
- coros: 3 時間 (10800 点) のランで、どのラップも 1000m・合計時間は変わらない
- 全体: 177 件合格・1 件スキップ (known-issues、従来どおり)
