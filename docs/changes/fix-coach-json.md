# AI コーチ「今週の見立て」に JSON がそのまま出る (2026-11-04)

## 原因
AI の返事が少し崩れた JSON だった (`reasons` の最後の文字列を `"` ではなく `」` で閉じ、配列の `]` も抜けていた)。
`parseCoach` は `JSON.parse` に失敗すると返事の文字列をそのまま表示していた。サーバーの `coach_brief` キャッシュとブラウザの sessionStorage にもその形で残るため、開き直しても直らなかった。

## 変更
- `src/coach.ts`
  - `repairJson`: 」で閉じた文字列・配列の閉じ忘れ・末尾のカンマ・最後の `}` の抜けを直す (正しい JSON はそのまま)
  - `looseJson`: そのまま → 直して → 項目ごとに拾う の順で読む
  - `plainText`: どうしても読めないときも、`{` `"` などの記号を除いた文章だけを出す
  - `coachBrief`: キャッシュに JSON のまま残った見立ては、読み直して返す (キャッシュは消さない)
- `public/app.js`: sessionStorage に JSON のまま残った見立てがあれば、会話を空にして取り直す
- `test/coach.test.ts`: 画面に出た形の崩れた返事など 6 件

## 変えていないもの
COROS・Strava の連携、評価の計算、保存済みのデータ。AI への指示文・モデルも変えていない。
