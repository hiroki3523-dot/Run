# 体調の保存ボタン・からだのデータ (ヘルスケア)・体重の目安 (2026-11-12)

ユーザー要望:
1. 今朝の体調の「保存」が触りにくい・目立たない
2. ヘルスケアから体重・体脂肪などを取り込み、その日の健康状態を詳しく管理したい
3. 目標タイムに対する体重の目安がほしい

## 1. 保存ボタン
- 原因: ボタンの見た目 (`.fbx-save`) が、ふりかえりの枠 (`.fbx`) の中にしか効いておらず、体調の枠では小さな普通のボタンだった
- 幅いっぱい・高さ 52px・アクセント色に

## 2. からだのデータ
- Web アプリ (PWA) は iPhone のヘルスケアを直接読めない。そこで iPhone の**ショートカット**で毎朝送る形にした (設定 › からだのデータ に作り方)
- API (今のトークンで認証):
  - `POST /api/body` (ショートカットから): 体重・体脂肪率・安静時心拍・HRV・睡眠時間。送った項目だけ上書き。日付が無ければ今日
  - `PUT /api/body/:date` (手入力): その日の値を入れ直す
  - `GET /api/body` (35 日分・身長・目安)
  - `PUT /api/body-profile` (身長)
- 保存先: kv `body:YYYY-MM-DD`・`body_profile` (バックアップにも入る)
- 受け取り: 体脂肪率は 0.152 でも 15.2 でも可・「72,4 kg」のような文字も読む。範囲外・読めない値は保存しない (0 や推測で埋めない)
- ホームの「今朝の体調」の下に「からだ」: 直近 7 日以内の最新値 (今日でなければ日付を付ける)・体重の 35 日の推移・「入力」で手入力

## 3. 体重と目標タイムの目安
- 目標体重は出さない。出すのは:
  - 7 日平均・4 週前との差・BMI (身長があれば)
  - 「同じ走力なら体重 1% ≈ タイム 1%」という一般的な目安から、次のフルの目標タイムでの 1kg あたりの秒数 (目標 3:10・72kg なら約 2 分 38 秒)
- 注意書き: あくまで目安・筋肉や回復力も落ちうる・食事を大きく減らさない・BMI 18.5 の体重を下回らない。BMI 20 未満なら「すでに軽め。練習と回復で」と出す

## 変えていないもの
COROS・Strava の連携、評価の計算、今朝の体調の保存データ
