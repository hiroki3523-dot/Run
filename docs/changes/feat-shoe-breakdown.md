# シューズ: 累計の内訳 (記録＋補正) を出す・補正を意図せず変えない

## きっかけ
- 20km 走ったのに、シューズの累計が 12km のまま増えないように見えた
- 累計 = そのシューズで走ったランの合計 (記録) ＋ 補正 (Nike Run Club などに合わせて手で直した分)。記録が入ったあとに走行距離を直すと、その分を打ち消す補正 (マイナス) が入るが、画面に出ていなかった

## 変更
- シューズの詳細の「累計距離」の下に、補正があれば「記録 20.0 − 補正 8.0」のように内訳を出す (従来は「補正を含む」だけ)
- 編集画面の「走行距離」の下に、入力に合わせて「記録の合計 20.0km ＋ 補正 12.0km」を出す。記録より少なくするときは注意の色
- 保存: 走行距離を変えていなければ補正はそのまま (編集画面を開いている間に新しいランが入っても打ち消さない)。変えたときは、保存する時点の最新の記録の合計から補正を出す
- 手で合わせた補正の値そのものは、勝手に書き換えない

## 変えていないもの
- 累計の計算 (SHOE_TOTAL_SQL)・COROS・Strava の連携・既存のデータ
