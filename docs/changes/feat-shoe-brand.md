# シューズのブランドを名前と分ける (2026-11-05)

ユーザー要望: シューズ名にブランドを入れているので、ブランドの入力欄がほしい。ランニングシューズのブランドから選び、無ければ入力。相性の表で名前がはみ出しにくくなる。

- D1: `shoes.brand` を追加 (migrations/0007。NULL 可。既存の行・名前は変えない)
- 編集画面: 「ブランド」(Nike・adidas・ASICS・New Balance・HOKA・On・Saucony・Brooks・Mizuno・PUMA・Under Armour・Salomon・ALTRA・Reebok・361°・Diadora・その他 (入力)) と「モデル名」
  - ブランドが未設定で名前の先頭にブランドがある靴 (例: Nike ボメロ18) は、編集画面を開くと「Nike」+「ボメロ18」に分けた形を初期値にする。**保存したときだけ**変わる (自動で一括変更はしない)
- 表示: 一覧・詳細・相性の表は、ブランドを小さく 1 行・モデル名を大きく。ほかの場所 (おすすめ・通知など) は「ブランド モデル名」でこれまでと同じ見え方
- 「画像を探す」はブランド + モデル名で検索
- Strava から新しく作られる靴は今までどおり (ブランドは未設定)。Strava の連携処理は変えていない
- 累計距離 (手動で補正した値) は変えない

テスト (e2e): 「ASICS ノヴァブラスト 5」→ 編集画面で ASICS / ノヴァブラスト 5 に分かれる・保存で brand と name が分かれる・距離は変わらない・「その他」で入力したブランド名を保存
