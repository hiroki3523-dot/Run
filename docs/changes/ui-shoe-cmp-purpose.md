# シューズの相性: レース用の靴がジョグのおすすめに出る (2026-11-04)

ユーザー報告: レース用に設定しているアルファフライ 3 が、ジョグ・イージーの「スピード寄り」のおすすめに出る。

原因: 相性は「その種類のランで使った記録」だけで比べ、シューズに設定した用途を見ていなかった。

変更 (画面だけ):
- 練習の種類ごとに、おすすめの対象にする用途を決めた
  - ジョグ・イージー: イージー走・リカバリー/ジョグ・ロング走
  - ポイント練: ペース走・スピード練習・レース本番
  - ロング走: ロング走・イージー走・ペース走
  - インターバル: スピード練習・ペース走・レース本番
  - レース: レース本番・スピード練習・ペース走
- 用途が合わない靴は、表には出す (記録は本物なので消さない) が、「〜用」の印を付けて後ろに並べ、おすすめ・緑の印の対象から外す
- 用途が未設定の靴は、これまでどおり対象にする
- 集計・保存データ・シューズの用途の設定は変えていない

テスト: e2e でレース用の靴 (いちばん速い・走りやすさも高い) がおすすめにならない・後ろに並ぶ・「レース本番用」の印・緑の印が付かないことを確認。
