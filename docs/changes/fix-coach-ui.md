# AI コーチの回答表示・信頼性改善 / 「会話を消す」が効かない (2026-11-04)

指示書「STRIDE | AIコーチの回答表示・信頼性改善」と、ユーザー報告「AI との会話を消すが機能しなくなってる」への対応。

## 「会話を消す」の原因
押すと会話を空にした直後に「今週の見立て」を自動で取り直していた。状況が同じだとサーバーのキャッシュから**同じ見立て**が返るため、消えていないように見えた。
→ 消したあとは自動で出し直さない (この画面を開いている間)。「今週の見立てを出す」ボタンで出せる。

## サーバー (src/coach.ts)
- `parseCoach`: コードフェンス・二重にエンコードされた文字列・崩れた JSON (#126) に対応。型を確かめる (理由・維持する練習は文字列だけ)
- 読めないときは**元の文字列を返事に入れない**。`invalid: true` と利用者向けの文 (「回答をうまく表示できませんでした。もう一度お試しください。」) を返す
- 前の版の「項目を正規表現で切り出す」処理はやめた (内容を壊すおそれ)
- `coachBrief`: 読めなかった見立てはキャッシュしない。JSON のまま保存されていた古い見立ては読み直し、読めなければ作り直す
- AI への指示文・モデル・判断の決まり (大会前の調整など)・計画の保存方法は変えていない

## 画面 (public/app.js `wireCoach`)
- 通常の相談と今週の見立てを**同じカード** (`coachMsg` で整えて `aiCard` で描く) で表示
  - 見出し「AIコーチの見立て」+ 種別 (今週の見立て / 相談への回答) + 「計画変更なし」/「変更案あり：N件」
  - 結論 (3 行まで、長ければ「続きを表示」) → 判断した理由 (折りたたみ) → 予定どおりにする練習 → コーチのコメント (折りたたみ) → 変更案
- 変更案: 日付・変更前 → 変更後を表示。「予定に反映する…」→ 確認 (「反映する」/「やめる」) を押したときだけ保存。変更が無いときはボタンを出さない
- 読めない返事: 「回答をうまく表示できませんでした。もう一度お試しください。」+「もう一度試す」
- 通信エラー: 「AIコーチに接続できませんでした。」+「もう一度試す」(無料枠を使い切ったときだけ、その説明を添える)
- sessionStorage に残っていた古い会話も同じ形に整え、JSON のままのものは「読めなかった」扱い
- 読めなかった返事・エラーは AI に送り返さない
