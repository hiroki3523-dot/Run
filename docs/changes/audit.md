## 変更前と変更後の違い

- 変更前: 自動テストはあったが、実行するしくみ (CI) が無く、以前から失敗するテストが 1 件残っていた。画面と API を通したテストは無かった

## 変更した理由

- 機能が増えて、手で全画面を確認するのが難しくなったため (ユーザーの依頼)
- ChatGPT などの第三者レビューに渡すデータをまとめるため
