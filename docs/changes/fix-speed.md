# 表示を軽くする・通信の速さの記録・COROS のラップ・押しやすさ

## 変更
- 計画の画面を開き直したとき、AI コーチの欄は自動で開かない (開くたびに AI が動いて重くなっていたおそれ)。押したときだけ動く。ほかの欄 (予定をコピーなど) は従来どおり開き直す
- シューズの相性 (/shoes/compare) の計算結果をとっておく (最長 6 時間)
  - 計算に使うデータ (ラン・計画の種類・シューズ・分析・評価・体調・設定) が変わったら作り直す
  - 評価 (ふりかえり) と体調を保存したときは、とっておいた結果を必ず捨てる
  - とっておいた結果はバックアップに含めない
- 設定に「通信の速さ」: この端末で、画面が出るまでと各読み込みにかかった時間 (最近 120 件・回数・ふつう・最大)。重いときの原因調べ用

- COROS のランの 1km ごとのラップ: 時計の一時停止 (オートポーズ) 中の時間を入れない (利用者の了承済み)
  - 例: 11/14 の 10.16km で、1・2・9・10km が 6:04 / 6:01 / 5:15 / 5:49 になっていた (COROS では 5:11 / 5:10 / 4:43 / 5:22)。差の合計 2:42 = 合計時間 53:10 − 走っていた時間 50:28
  - 記録が途切れた間 (5 秒を超える間) は 1 秒だけ数え、まだ時計のタイマー時間より長ければ、距離が進んでいない区間を除いて合わせる
  - 変えたのは受け取った記録を 1km ごとに区切る計算だけ。通信・認証・同期の流れ、合計の距離・時間は変えていない。これから入るランから正しくなる (過去のランの取り直しはしない)
- 押しやすさ
  - ふりかえりの選択肢 (あと何 km 続けられそう) を、行全体が押せる大きな枠に。選んだものは色で分かる
  - ふりかえりの「この評価を保存」を、体調の保存と同じ大きく目立つ色に
  - 計画の編集の下にも大きな「保存」(右上まで指を伸ばさなくてよい)
  - 小さなボタン (修正・計画・目標・身長など) を少し大きく。文字だけのボタン (追加済みにする・公式サイトを探す・画像) は見た目はそのまま押せる範囲を広げる
  - チェックボックスの行を高く

## 変えていないもの
- COROS・Strava の連携・同期、データ
